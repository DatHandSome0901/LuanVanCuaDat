# Lam Son Cropped Reference Assets

Các ảnh trong thư mục này được crop thô từ concept sheet bạn gửi.

Lưu ý:
- Đây là ảnh reference/cutout thô, chưa phải sprite sheet chuẩn nền trong suốt.
- Có thể dùng tạm để làm landing page, UI showcase, hoặc placeholder image-based trong Phaser.
- Để đưa vào game đẹp hơn, nên tách nền thủ công/AI và xuất PNG trong suốt từng nhân vật.
- Animation thật vẫn nên dùng sprite sheet riêng hoặc dùng tween/bobbing/slash effect.

Gợi ý dùng nhanh:
- hero_idle_ref.png: player placeholder
- enemy_infantry_ref.png: lính bộ binh
- enemy_archer_ref.png: lính cung
- enemy_spearman_ref.png: lính giáo
- enemy_swordsman_ref.png: lính kiếm
- enemy_cavalry_ref.png: lính kỵ
- boss_ref.png / boss_front_ref.png: boss placeholder
- boss_skill_effect_ref.png: hiệu ứng boss
